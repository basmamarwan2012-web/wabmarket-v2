# Project Vision

Wabmarket is an AI-powered domain acquisition, branding, lead-generation, outreach, and sales platform.

The platform automates the entire domain-flipping lifecycle.

The platform must:

- discover domains;
- evaluate domains;
- calculate FlipScore;
- purchase domains;
- synchronize purchased domains;
- generate leads;
- create branding assets;
- generate sales material;
- launch campaigns;
- negotiate with buyers;

- maximize ROI.
